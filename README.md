AI RESUME CRITIQUER
An AI-powered web application that analyzes resumes and provides personalized feedback to improve content quality, ATS compatibility, and job-role alignment.

FEATURES
--Upload resumes in PDF format
--Extracts text using PyPDF2
--Analyzes resume content with Google Gemini API
--Generates structured feedback on skills, experience, and presentation
--Provides ATS-focused improvement suggestions
--Simple and interactive Streamlit interface

TECH STACK
--Python
--Streamlit
--PyPDF2
--Google Gemini API
